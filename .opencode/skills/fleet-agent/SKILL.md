# fleet-agent skill

Use Fritz tools for agent/orchestration work: `heartbeat_status()`,
`coworker_execute(flow=...)`, `fleet_discover()`, `workflow_status()`.

End of work: `evolution_record()` the lesson; leave the tree clean.
Shutdown: `fritz_shutdown()` (MCP) or POST /api/shutdown (HTTP).
